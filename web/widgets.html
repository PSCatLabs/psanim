psanim widgets

Each of these is a psanim movie running live in this page, rendered by the engine compiled to WebAssembly. The page feeds it inputs (the time of day, the pointer, a signal set from JavaScript) and it draws only when its frame changes or an input does. Scroll one off screen or hide the tab and it stops drawing.

Digital clock: entry="clock-digital", Signal=clock

Analog clock, sweeping second hand

Pointer: hover and click it

Spinners: entry="spinner"

Build status: entry="pipeline", driven by widget.setSignal("build", stage)
