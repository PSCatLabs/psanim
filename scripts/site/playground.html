Playground

The real engine, compiled to WebAssembly, running in this page. Edit the program; it re-runs as you type. Drag the scrubber: the frame under it is computed on the spot.

Errors appear over the canvas, with the frame, the command, a trace through your procedures and a hint. now == prints nowhere here yet; use the command line for that. The page cannot read files or encode video: for those, install the CLI.
