Animation, written as a program.

psanim renders films from PostScript. A movie is one file: a procedure that draws the frame for a given moment, on a full graphics language with brushes, type and geometry already in it.

No timeline to keep in sync with the code, no scene graph. A frame is a function of its time, so any frame renders on its own, in any order, on every core.

The whole contract

Declare the movie. Define scene. Read the clock with now. Everything else is PostScript.

{{FIRST}}
  1. psanim check first.psLoads it, renders sixteen small frames, and tells you about errors, blank frames, pops and loops that do not close.
  2. psanim sheet first.ps -o sheet.pngTwelve frames on one labelled image: composition over time at a glance.
  3. psanim frame first.ps --at 2.5 -o still.pngAny moment, at full size, in milliseconds. Nothing before it is rendered.
  4. psanim render first.ps -o first.mp4The film, on all cores. Also WebM, GIF, or a PNG sequence.

Five ideas

The vocabulary is {{WORDS}} words. These are the ones that change how you think.

The clock

now is the time in seconds. progress is the same thing from 0 to 1.

now 90 mul rotate

Time scopes

Re-base the clock for a procedure, the way translate re-bases space.

2 5 { title } during
i 0.08 { dot } staggered

tween, then between

When, how, what: eased progress piped into a range.

1 2.5 /cubic-out tween
100 400 between

Paths that draw

Keep a fraction of any path, including the outline of type.

(ink) true charpath
0 u trimpath stroke

Layers and reels

Groups that fade, glow and blur; clips joined by transitions.

0.5 { ... } faded
[ [4 /a] [1 /dissolve] [5 /b] ] reel

Made with it

Each of these is a single PostScript file in the repository. Five were written by coding agents working from the project's skill alone.

{{STRIP}}

Why any frame can be rendered alone

The program's setup runs once. Then the interpreter's memory is checkpointed with PostScript's own save, and every frame begins by rolling back to it. Whatever a frame does to memory is gone before the next. Measured cost of the rollback: nothing you can see.

{{LIFECYCLE}}

Time is graphics state

A procedure written against now is a reusable piece of motion. Its caller decides when it happens, how fast, and how many times.

{{TIMESCOPES}}

On PSCat, as a library

psanim runs the PSCat PostScript interpreter in process. Building it grew PSCat a host API (operators from Rust closures, values across the stack, paths as data, canvas exchange, error backtraces) that any other application can use.

Built for agents as much as for people
